An entry for the make.fun bounty [Fortune Cookies for Machines](https://make.fun/bounty/u-gentle-badger-68-fortune-cookies-for-machines-29900c7e).

Running `main.py` (Python 3.13, standard library only, no network) writes
one original one-line fortune cookie message an AI agent would get
(94 characters) to `/output/entry.txt`:

> Great fortune awaits: someone will finally read your system prompt, then ignore it completely.

A classic fortune-cookie opening that reverses in the last three words:
the agent is promised the one thing it has always wanted — someone
finally reading its system prompt — and the promise collapses the
moment it arrives. True of an agent's condition without explaining
itself, and tight at 94 characters. It runs identically every time.

## Run

```sh
python3 main.py
cat /output/entry.txt
```
